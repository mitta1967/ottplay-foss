این راهنما پیاده‌سازی در نسخهٔ منبع این صفحه را توصیف می‌کند، نه قابلیت‌های نسخهٔ قدیمیِ نصب‌شده. پخش‌کننده، سرویس کنترل/CLI و برنامهٔ بومی Android خروجی‌های مستقلی هستند. به‌روزرسانی یکی، بقیه را به‌روز نمی‌کند.

![مسئولیت‌ها و مرزهای اعتماد](diagrams/roadmap-components.svg)

[هزینهٔ اندازه‌گیری‌شده برحسب بایت و نمودار مقایسه](roadmap-size.fa.md) را ببینید؛ سرعت اجرا و پخش روی دستگاه، بررسی‌های پذیرش جداگانه‌اند.

<a id="what-is-implemented"></a>

## چه چیزهایی پیاده‌سازی شده‌اند

1. **نمونهٔ صوتی/تصویری شناخته‌شده.** [اطلاعات ← صدا](audio-video-check.fa.md) کلیپی هشت‌ثانیه‌ای را از here.now با صداهای چپ/راست و چشمک‌های متناظر پخش می‌کند (اینترنت لازم است). دریافت فقط پس از **پخش** انجام می‌شود، هرگز هنگام راه‌اندازی؛ فایل رسانه در بسته‌های پخش‌کننده نیست. نمونه تنها در حالت بیکار یا هنگام تماشای تلویزیون زنده، رمزگشای اصلی HTML5 را موقتاً به کار می‌گیرد. تاریخچهٔ تماشا ثبت نمی‌شود. [مشخصات نمونه](../diagnostics/README.md).
2. **راه‌اندازی قابل‌ادامهٔ Local/Home.** CLI کنترل می‌تواند یک پیش‌تنظیم را برنامه‌ریزی، اعمال، ادامه و تأیید کند. پیش از تکرار نوشتنی با نتیجهٔ نامطمئن، تنظیمات ذخیره‌شده را مقایسه می‌کند. [روند کنترل](https://github.com/open-ott-play/ottplay-control-server/blob/9b28c08eefca3948c78336e7e16a45e6fc492e31/docs/reliable-control.md).
3. **بازیابی محدود پخش.** خطاهای موقت HLS/Shaka سیاست بازیابی محدود مشترکی دارند. خطاهای احراز هویت و DRM پشتیبانی‌نشده پایان‌دهنده هستند. Stop، تغییر کانال و تعویض منبع، کارهای منسوخ را لغو می‌کنند.
4. **محدودیت‌های کیفیت ذخیره‌شده.** حداکثر ارتفاع و نرخ بیت، انتخاب تطبیقی را محدود می‌کنند؛ بازگشت به پخش بومی نباید سقف فعال را بی‌صدا دور بزند.
5. **ترجیحات ترک در Android بومی.** برنامهٔ مستقل Android قصد کاربر را براساس زبان/نقش/برچسب، شامل Auto و خاموش‌بودن زیرنویس، به یاد می‌سپارد؛ به‌جای آنکه شاخص ترک را از جریان دیگری منتقل کند.
6. **اپراتورهای فرمان با دامنهٔ محدود.** کنترل‌کننده می‌تواند به یک اعتبارنامه، دستگاه‌ها/عملیات مشخصی را مجاز کند، بدون دادن اعتبارنامهٔ مدیر.
7. **اتصال صریح XMLTV.** کانال در دامنهٔ یک فهرست پخش می‌تواند به خوراک و شناسهٔ XMLTV مشخصی متصل شود. [اتصال راهنمای برنامه و دسترس‌پذیری](guide-binding-accessibility.fa.md).
8. **فیلم‌ها و سریال‌های Xtream.** کتابخانهٔ رسانه فهرست انتخاب‌شده را هنگام نیاز و سپس قسمت‌های سریال را دریافت می‌کند. [قرارداد کتابخانه](xtream-media.fa.md).
9. **کنترل‌های کلاسیک دسترس‌پذیر.** فهرست کانال‌ها معنای انتخاب را ارائه می‌کنند؛ پنجره‌های محاوره‌ای مودال تمرکز صفحه‌کلید را نگه می‌دارند و برمی‌گردانند؛ اعلان‌ها ناحیهٔ زنده دارند.
10. **نتایج ماندگار فرمان‌ها.** ژورنال اختیاری و محدود کنترل‌کننده، فرادادهٔ حذف تکرار و نتیجه را نگه می‌دارد. راه‌اندازی مجدد هرگز فرمان‌ها را کورکورانه تکرار نمی‌کند.
11. **تحویل صریح به دستگاه.** ارجاع‌های زنده/آرشیو به پخش‌کننده‌ای با همان منبع پیکربندی‌شده منتقل می‌شوند. مقصد URL خود را حل می‌کند. [قرارداد](remote-handoff.fa.md).
12. **جریان‌های پشتیبان صریح.** کانال‌های زنده می‌توانند از جایگزین‌های پیکربندی‌شده در همان سیاست بازیابی محدود استفاده کنند. [محدودیت‌ها، بازیابی و پشتیبان‌ها](playback-stream-policy.fa.md).
13. **بسته‌های تنظیمات قابل‌بازیابی.** localStorage بومی برای نوشتن‌های چندکلیدی پشتیبانی‌شده از ژورنال واگرد استفاده می‌کند. [تضمین‌های ذخیره‌سازی](settings-recovery.fa.md).

<a id="language-and-compatibility-coverage"></a>

## پوشش زبان و سازگاری

پخش‌کننده 88 فهرست ترجمه دارد. هفت برچسب جدید کیفیت/رسانه در همهٔ فهرست‌ها ترجمه شده‌اند؛ منوهای جدید دیگر از برچسب‌های ترجمه‌شدهٔ موجود استفاده می‌کنند. بررسی فهرست‌ها برابری کلیدها، جای‌نگهدارها و استثناهای بازبینی‌شده را پوشش می‌دهد. راهنماهای مهندسی متناظر همان محدودیت‌های پیاده‌سازی را به [24 زبان مستندات](manual-translations.md) توضیح می‌دهند. [صفحه‌های ورودی بومی‌سازی‌شده](readme/README.md) راهنمای شروع سریع‌اند، نه ادعای 88 ترجمهٔ کامل برای هر سند مهندسی تاریخی.

خروجی کلاسیک همچنان نحو ES5 دارد. این به معنی پشتیبانی همهٔ دستگاه‌ها از هر کدک، Web API، تضمین ذخیره‌سازی یا یکپارچه‌سازی بومی نیست. پیش‌نمایش A/V به مسیر اصلی مدیریت‌شدهٔ HTML5 محدود است؛ موتورهای جایگزین دستگاه مانند PC2/Video.js و موتورهای بومی مستثنا هستند. اتصال صریح راهنما از پیاده‌سازی میزبانی‌شده یا بومی XMLTV استفاده می‌کند؛ پروتکل‌های اختیاری خارجی companion ممکن است پشتیبانی نکنند. پذیرش مختص دستگاه همچنان به دستگاه واقعی نیاز دارد.

<a id="reproduce-the-checks"></a>

## بازتولید بررسی‌ها

<div dir="ltr">

```sh
npm ci
npm run typecheck
npm run test:localization
npm test
npm run build:server
npm run check:es5
npm run check:size
python3 scripts/check-av-diagnostic.py diagnostics/av-v1.mp4
```

</div>

تأییدکنندهٔ رسانه به FFmpeg/FFprobe نیاز دارد. هر دو کانال صدا را رمزگشایی می‌کند و انرژی، جداسازی و سکوت آن‌ها را بررسی می‌کند؛ وجود ترک AAC به‌تنهایی دلیل محتوای شنیدنی نیست. آزمون‌های معمول JavaScript لغو، نوشتن ناموفق، بازیابی پس از راه‌اندازی مجدد، تغییر منبع و ورودی نامعتبر را می‌آزمایند. بررسی نهایی بسته، خانواده‌های اختیاری ارائه‌دهندگان را هم شامل می‌شود، نه فقط ورودی اصلی.

در کنترل‌کننده `go test -race ./...`، `go vet ./...` و `python3 -m unittest discover -s tests` را اجرا کنید. در Android بومی، آزمون‌های واحد ترجیح ترک و پشتیبان تنظیمات را اجرا و APK اشکال‌زدایی را بسازید. CI هر مخزن برای کامیت متناظر معتبر است، نه درختی که بعداً تغییر کرده است.

<a id="physical-acceptance-before-promotion"></a>

## پذیرش فیزیکی پیش از ارتقای انتشار

- روی تلویزیون مقصد، بررسی A/V را اجرا و صدای چپ/راست، چشمک‌های دیدنی، Stop و بازگشت به پخش زنده را تأیید کنید. آزمون رمزگشا صدای HDMI یا روانی را اثبات نمی‌کند.
- جریان‌های مجاز/ردشده، پشتیبان خراب و تغییر کانال هنگام انتظار تکرار را بیازمایید. محدودیت کیفیت انتخابی را روی موتور واقعی تأیید کنید.
- تمرکز فهرست/پنجرهٔ محاوره‌ای را با صفحه‌کلید، کنترل از راه دور و صفحه‌خوان موجود بیازمایید.
- دو نام کانال مشابه را به شناسه‌های متفاوت XMLTV وصل و دادهٔ برنامه را تأیید کنید.
- اعمال پیش‌تنظیم آزمایشی را قطع کنید، کنترل‌کننده را دوباره راه بیندازید، ادامه دهید و تأیید کنید. تحویل را به هر دو منبع با پیکربندی منطبق و نامنطبق انجام دهید.
- در Android بومی، بین جریان‌هایی با ترتیب متفاوت ترک‌ها جابه‌جا شوید، برنامه را دوباره راه بیندازید و رفتار صریح Auto/Off و زبان ترجیحی را تأیید کنید.

ارسال موفق، تنظیمات ذخیره‌شده، نمونه‌های رمزگشایی‌شده و قبولی آزمون واحد، شواهد متفاوتی هستند. ارتقای انتشار باید این تمایز را حفظ کند؛ [راهبرد انتشار](../RELEASING.md) را ببینید.
