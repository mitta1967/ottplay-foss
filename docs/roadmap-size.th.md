![เปรียบเทียบ JavaScript ทั้งหมดของเครื่องเล่นด้วยชุดเครื่องมือเดียวกัน](diagrams/roadmap-size.svg)

หน้านี้เก็บผลวัด JavaScript จากสแนปช็อตซอร์สด้านล่าง ผลเหล่านี้ไม่ได้วัดรีวิชันปัจจุบัน แพ็กเกจติดตั้ง หรือการรับส่งข้อมูลเครือข่าย

ในการเปรียบเทียบแรก จุดเข้าหลักรวมผู้ให้บริการเสริมทุกตระกูลเพิ่มขึ้น **31 128 ไบต์ดิบ / 9 759 ไบต์ gzip** ประมาณ **3.23% / 3.20%** เป็นต้นทุนฟีเจอร์ที่เพิ่มขึ้น ไม่ใช่ข้ออ้างว่าขนาดหรือความเร็วประมวลผลดีขึ้น Xtream ยังโหลดเมื่อจำเป็น การย้ายออกจากจุดเข้าไม่ได้ตัดออกจากยอดรวม

การวัดเปรียบเทียบอาร์ไคฟ์ซอร์สสะอาด `bbf9ca7b` และ `cae971da` ซึ่งเป็นรุ่น 1.1.55 ทั้งคู่ ด้วย Node 26.8.2, TypeScript 5.9.3, Terser 5.51.2 และ zlib 1.2.12 ใช้ตัวประกอบ ES5 สำหรับงานจริง ตัวปรับประสิทธิภาพ นโยบายชื่อ และอัตลักษณ์ซอร์สสะอาดที่ถูกต้อง ใช้ gzip ระดับ 9 แยกกับทรัพยากรแต่ละไฟล์ที่สร้างออกมา

- จุดเข้าเว็บ: 848 092 / 262 392 → 874 926 / 270 321 ไบต์ดิบ/gzip
- จุดเข้าเว็บ + ผู้ให้บริการทั้งหมด: 964 459 / 305 344 → 995 587 / 315 103
- จุดเข้าเนทีฟ: 848 050 / 262 460 → 874 884 / 270 372
- จุดเข้าเนทีฟ + ผู้ให้บริการทั้งหมด: 964 417 / 305 412 → 995 545 / 315 154
- M3U เสริมเพิ่ม 184 ไบต์ดิบ / 82 gzip ส่วน Xtream ใหม่เป็น 4 110 / 1 748 อีกหกตระกูลเสริมเหมือนเดิมทุกไบต์

ก่อนย้ายคลิปไป here.now การเปลี่ยน URL เป็นพาธภายในจากรากเพิ่ม JavaScript ดิบหนึ่งไบต์ในลำดับการเปลี่ยนแปลงย้อนหลังนี้ ไม่ใช่การวัด URL ที่โฮสต์ภายหลัง การแก้การลองแยกวิเคราะห์ HLS ซ้ำแบบจำกัดเพิ่ม 37 ไบต์ดิบ / 36 gzip ในการเปรียบเทียบสแนปช็อตเดียวกันแบบแยกส่วน ([หลักฐาน](evidence/parse-recovery-size-20261015.json)) การแก้ความเป็นเจ้าของการส่งต่อ Auto แบบเนทีฟเพิ่มอีก 101 ไบต์ดิบ / 39 gzip ([หลักฐาน](evidence/auto-recovery-size-20261015.json)) ยอดรวมดิบก่อนแก้ปัญหาถดถอยด้านการเข้าถึงจึงเป็น 995 726 ไบต์ อัตลักษณ์บิลด์และไบต์ gzip อาจเปลี่ยนในคอมมิตสุดท้าย โดย `build/reports/classic-bundle.json` และ `npm run check:size` สุดท้ายยังเป็นหลักอ้างอิงสำหรับรีวิชันที่ส่งมอบจริง บิลด์สะอาดถัดมา `652726f8` ซึ่งรวมการแก้โฟกัสตัวชี้/กล่องโต้ตอบ วัดเครื่องเล่นเว็บทั้งหมดได้ **995 858 ไบต์ดิบ / 315 207 gzip** ([หลักฐานอาร์ติแฟกต์สุดท้าย](evidence/roadmap-final-size-20261015.json)) จุดเข้าเป็น 875 197 / 270 425 ยอดรวมเนทีฟเป็น 995 816 / 315 259 เพดานของสแนปช็อตนั้นคงพื้นที่เผื่อเดิมสำหรับเนทีฟ/Node/ส่วนต่อท้ายรุ่น คือ 875 300 ดิบ / 271 600 gzip สำหรับจุดเข้า และ 996 100 / 316 400 สำหรับจุดเข้า + ผู้ให้บริการ

## การรวมงานหลังเบตา

![JavaScript ทั้งหมดหลังรวม beta.4](diagrams/post-beta-size.svg)

การเปรียบเทียบภายหลังสร้างซอร์ส beta.4 `39287792` ซ้ำเทียบกับรันไทม์ `9663b681` ซึ่งรวม Plex และการกู้คืนการตั้งค่าที่เสียหาย โดยใช้ Node 26.8.2, Rollup 4.64.5 และ Terser 5.51.2 ชุดเดียวกัน:

- จุดเข้าเว็บ: 848 315 / 262 443 → 879 533 / 271 761 ไบต์ดิบ/gzip
- จุดเข้าเว็บ + ผู้ให้บริการทั้งหมด: 964 876 / 305 452 → 1 000 388 / 316 600
- จุดเข้าเนทีฟ + ผู้ให้บริการทั้งหมด: 964 834 / 305 520 → 1 000 346 / 316 654
- เพย์โหลดเว็บทั้งหมดเพิ่ม: **35 512 / 11 148 ไบต์ (3.68% / 3.65%)**

ฐานอ้างอิงนับผู้ให้บริการเจ็ดตระกูล ส่วนที่รวมงานนับแปดตระกูล รวม Xtream ที่โหลดเมื่อจำเป็น เพดานจุดเข้าของสแนปช็อตนั้นคือ 879 900 / 273 000 เพดานรวมคือ 1 000 800 / 317 800 โดยเผื่อเนทีฟ Node และอัตลักษณ์รุ่น บิลด์ใช้งานจริงภายในเครื่องทั้งสองสร้างไฟล์รันไทม์ที่ติดตามอยู่ห้าไฟล์ใหม่และไม่อ้างว่าเป็นรีวิชันซอร์สสะอาด นี่คืออาร์ติแฟกต์ที่สร้างซ้ำภายในเครื่อง ไม่ใช่ไบนารีเบตาที่เผยแพร่ รุ่นเครื่องมือ แฮช และข้อจำกัดนี้บันทึกใน[หลักฐานฐานอ้างอิง](evidence/post-beta-baseline-size-20261015.json)และ[หลักฐานการรวมงาน](evidence/post-beta-candidate-size-20261015.json) [รายงานการพัฒนา](implementation-report.th.md#post-beta-integration-and-review)อธิบายการแก้ไขและตรวจสอบ

**ขอบเขต:** ยอดรวม JavaScript นี้ไม่รวมเอนจินสื่อภายนอก พจนานุกรมภาษา CSS รูปภาพ และวิดีโอ แพ็กเกจเครื่องเล่นในอดีตยังมี **คลิป A/V ขนาด 464 652 ไบต์** ซึ่งอยู่นอกยอดรวมข้างต้น การส่งมอบปัจจุบันแยกจากการวัดเหล่านี้:

- **ที่เก็บโค้ด:** `diagnostics/av-v1.mp4` ยังคงอยู่กับตัวสร้างและตัวตรวจสอบเพื่อให้ทำซ้ำได้ การเก็บไฟล์ซอร์สไม่ได้หมายถึงรวมไว้ในแพ็กเกจ
- **แพ็กเกจ:** Web/OTTPlay Server, Tauri, Capacitor และ Docker ไม่รวมคลิป จึงตัดทรัพยากรสื่อดิบ 464 652 ไบต์ ไม่ใช่การลดขนาดตัวติดตั้งแบบบีบอัดที่วัดได้ 464 652 ไบต์ รูปแบบอาร์ไคฟ์และการเปลี่ยนบิลด์อื่นมีผลต่อขนาดนั้น
- **เครือข่าย:** เครื่องเล่นดึงคลิปจาก here.now เฉพาะเมื่อผู้ใช้เริ่ม[ตรวจ A/V](audio-video-check.th.md) การตรวจต้องใช้อินเทอร์เน็ตและไม่ดึงคลิปสำหรับการเล่นตอนเริ่มโปรแกรม

ผลวัด JavaScript ในอดีตด้านบนไม่เปลี่ยน การวัดผลของ URL ที่โฮสต์ต่อ JavaScript หรือตัวติดตั้งปัจจุบันต้องเปรียบเทียบใหม่ README ที่แปล 88 ภาษาเป็นเอกสารในที่เก็บโค้ด ไม่ใช่เพย์โหลดเครื่องเล่น การเทียบไบต์นี้ไม่รองรับข้ออ้างด้านเวลาเริ่มต้น อัตราเฟรม หน่วยความจำ หรือประสิทธิภาพเมื่อแค็ตตาล็อกใหญ่ ต้องวัดสิ่งเหล่านั้นแยกบนอุปกรณ์เป้าหมาย
