## ما تم تنفيذه

1. **عينة صوت وفيديو معروفة.** يشغّل [المعلومات ← الصوت](audio-video-check.ar.md) مقطعًا مدته ثماني ثوانٍ من here.now (يتطلب الإنترنت)، بنغمات يسرى/يمنى وومضات مطابقة. لا يُجلب إلا بعد **تشغيل**، ولا يُجلب عند بدء التطبيق؛ ملف الوسائط غير مضمن في حزم المشغّل. يستعير مفكك HTML5 الرئيسي فقط أثناء الخمول أو مشاهدة البث المباشر. لا يكتب سجل مشاهدة. [مواصفات العينة](../diagnostics/README.md).
2. **إعداد Local/Home قابل للاستئناف.** تستطيع واجهة التحكم CLI تخطيط إعداد مسبق وتطبيقه واستئنافه والتحقق منه. تقارن الإعدادات المحفوظة قبل إعادة محاولة كتابة نتيجتها غير مؤكدة. [سير عمل التحكم](https://github.com/open-ott-play/ottplay-control-server/blob/9b28c08eefca3948c78336e7e16a45e6fc492e31/docs/reliable-control.md).
3. **استعادة تشغيل محدودة.** تشترك أخطاء HLS/Shaka العابرة في سياسة استعادة محدودة. أخطاء المصادقة وDRM غير المدعوم نهائية. يلغي Stop وتغيير القناة واستبدال المصدر العمل المتقادم.
4. **حدود جودة محفوظة.** يقيد أقصى ارتفاع ومعدل بت الاختيار التكيفي؛ يجب ألا يتجاوز الرجوع إلى التشغيل الأصلي سقفًا نشطًا بصمت.
5. **تفضيلات المسارات في Android الأصلي.** يتذكر تطبيق Android المستقل النية بحسب اللغة/الدور/التسمية، بما فيها Auto وإيقاف الترجمة، بدل نقل فهرس مسار من بث آخر.
6. **مشغّلو أوامر بصلاحيات محددة.** يمكن لوحدة التحكم منح بيانات اعتماد أجهزة/إجراءات بعينها دون تسليم بيانات اعتماد المدير.
7. **روابط XMLTV صريحة.** يمكن ربط قناة ضمن نطاق قائمة تشغيل بتغذية ومعرّف XMLTV محددين. [ربط الدليل وإمكانية الوصول](guide-binding-accessibility.ar.md).
8. **أفلام ومسلسلات Xtream.** تجلب مكتبة الوسائط الكتالوج المحدد عند الحاجة، ثم حلقات المسلسل. [عقد المكتبة](xtream-media.ar.md).
9. **عناصر تحكم كلاسيكية ميسّرة.** تكشف قوائم القنوات دلالات الاختيار؛ تحفظ الحوارات المشروطة تركيز لوحة المفاتيح وتعيده؛ وتحتوي الإشعارات على منطقة حية.
10. **نتائج أوامر دائمة.** يحتفظ سجل اختياري محدود لوحدة التحكم ببيانات إزالة التكرار والنتائج. لا تعيد إعادة التشغيل تنفيذ الأوامر عميانيًا أبدًا.
11. **تسليم صريح إلى جهاز.** تنتقل مراجع المباشر/الأرشيف إلى مشغّل له المصدر المكوّن نفسه. تحل الوجهة عنوان URL الخاص بها. [العقد](remote-handoff.ar.md).
12. **بث احتياطي صريح.** يمكن للقنوات المباشرة استخدام بدائل مكوّنة ضمن سياسة الاستعادة المحدودة نفسها. [الحدود والاستعادة والبدائل](playback-stream-policy.ar.md).
13. **دفعات إعدادات قابلة للاستعادة.** يستخدم localStorage الأصلي سجل تراجع للكتابات المدعومة متعددة المفاتيح. [ضمانات التخزين](settings-recovery.ar.md).

## تغطية اللغات والتوافق

يتضمن المشغّل 88 كتالوج ترجمة. تسميات الجودة/الوسائط السبع الجديدة مترجمة في كل كتالوج؛ وتعيد القوائم الجديدة الأخرى استخدام التسميات المترجمة الموجودة. تغطي فحوص الكتالوج تكافؤ المفاتيح والعناصر النائبة والاستثناءات المراجعة. تشرح الأدلة الهندسية المتناظرة حدود التنفيذ نفسها في [24 لغة توثيق](manual-translations.md). [نقاط الدخول المترجمة](readme/README.md) أدلة بدء سريع، وليست ادعاءً بأن لكل مستند هندسي تاريخي 88 ترجمة كاملة.

يبقى الناتج الكلاسيكي بصياغة ES5. لا يعني ذلك أن كل جهاز يدعم كل ترميز أو Web API أو ضمان تخزين أو تكامل أصلي. تقتصر معاينة A/V على مسار HTML5 الرئيسي المُدار؛ وتُستثنى محركات الأجهزة التي تستبدله مثل PC2/Video.js والمحركات الأصلية. يستخدم ربط الدليل الصريح تنفيذ XMLTV المستضاف أو الأصلي؛ وقد لا تدعمه بروتوكولات companion الخارجية الاختيارية. لا يزال القبول الخاص بالجهاز يتطلب الجهاز الفعلي.

## إعادة تنفيذ الفحوص

<div dir="ltr">

```sh
npm ci
npm run typecheck
npm run test:localization
npm test
npm run build:server
npm run check:es5
npm run check:size
python3 scripts/check-av-diagnostic.py diagnostics/av-v1.mp4
```

</div>

يتطلب مدقق الوسائط FFmpeg/FFprobe. يفك ترميز قناتي الصوت ويفحص طاقتهما والفصل والصمت؛ وجود مسار AAC وحده ليس دليلًا على محتوى مسموع. تختبر اختبارات JavaScript المعتادة الإلغاء والكتابات الفاشلة والاستعادة بعد إعادة التشغيل وتغييرات المصدر والمدخلات غير الصالحة. تشمل فحوص الحزمة النهائية عائلات المزوّدين الاختيارية، لا نقطة الدخول الرئيسية فقط.

في وحدة التحكم شغّل `go test -race ./...` و`go vet ./...` و`python3 -m unittest discover -s tests`. في Android الأصلي شغّل اختبارات الوحدة لتفضيلات المسارات ونسخ الإعدادات الاحتياطية وابنِ APK التصحيح. CI لكل مستودع مرجع للالتزام المقابل، لا لشجرة تغيّرت لاحقًا.

<a id="physical-acceptance-before-promotion"></a>

## القبول الفعلي قبل ترقية الإصدار

- على التلفاز المستهدف، شغّل فحص A/V وتأكد من الصوت الأيسر/الأيمن والومضات المرئية وStop والعودة إلى البث المباشر. اختبارات المفكك لا تثبت صوت HDMI أو السلاسة.
- اختبر البث المسموح/المرفوض وبديلًا فاشلًا وتغيير القناة أثناء انتظار إعادة المحاولة. تحقق من حد الجودة المختار على المحرك الفعلي.
- اختبر تركيز القوائم/الحوارات بلوحة مفاتيح وجهاز تحكم وقارئ شاشة متاح.
- اربط اسمَي قناة متشابهين بمعرّفي XMLTV مختلفين وتحقق من بيانات البرامج.
- اقطع تطبيق إعداد مسبق للاختبار، وأعد تشغيل وحدة التحكم ثم استأنف وتحقق. سلّم التشغيل إلى مصدر مكوّن مطابق وآخر غير مطابق.
- على Android الأصلي، بدّل بين بثوث تختلف في ترتيب المسارات، وأعد تشغيل التطبيق وتحقق من Auto/Off الصريحين وسلوك اللغة المفضلة.

نجاح الإرسال والإعدادات المحفوظة والعينات المفكوكة واختبارات الوحدة الناجحة أدلة مختلفة. يجب أن تحافظ ترقية الإصدار على هذا التمييز؛ راجع [استراتيجية الإصدار](../RELEASING.md).
