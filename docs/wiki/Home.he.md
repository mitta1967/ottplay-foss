זהו דף הבית של התיעוד מנוהל הגרסאות במאגר המקור. GitHub יכול להציג ישירות דפי Markdown אלה; ניהולם כאן משאיר את ההוראות, התרשימים והבדיקות באותה סקירה עם הקוד. [GitHub Wiki](https://github.com/open-ott-play/ottplay-foss/wiki) הנפרדת מיוצאת ממקורות אלה ומציינת את גרסת המקור בכל דף. ראו [הוראות פרסום](../wiki-publishing.md).

## התחלה והתקנה

- [מדריך מעשי](../../README.he.md), זמין ב־[24 שפות תיעוד](../manual-translations.md).

- [חבילות ועדכוני Android Full/API 22](../android-distributions.md), [בניית Android](../../android/README.md) ו־[Capacitor iOS/Android](../capacitor-mobile.md).
- [הפצת שולחן עבודה ב־macOS](../macos-local-delivery.md), [חתימה/עדכון Tauri](../tauri-updater-notarize.md) ו־[מופעי HTTP מקומיים](../local-http-deployment.md).
