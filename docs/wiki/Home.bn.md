[README](../../README.bn.md) · [ইন্টারফেসের সব ভাষা](../readme/README.md)

এটি সোর্স রিপোজিটরিতে সংস্করণ-নিয়ন্ত্রিত নথির প্রধান পৃষ্ঠা। GitHub এই Markdown পৃষ্ঠাগুলো সরাসরি দেখাতে পারে; এখানে রাখলে নির্দেশনা, চিত্র ও পরীক্ষা কোডের সঙ্গে একই পর্যালোচনায় থাকে। আলাদা [GitHub Wiki](https://github.com/open-ott-play/ottplay-foss/wiki) এই উৎস থেকে এক্সপোর্ট হয় এবং প্রতিটি পৃষ্ঠায় সোর্স রিভিশন জানায়। [প্রকাশের নির্দেশনা](../wiki-publishing.md) দেখুন।
