השתמשו ב-**תפריט הנגן ← מידע ← אודיו ← ניגון** כדי לבדוק תמונה וצליל עם קטע מוכר בן שמונה שניות. זו בדיקת A/V שנשמעת; הדגמת התבנית הנעה בעת ההיכרות עם היישום שקטה.

![בדיקת A/V: מקור במאגר, קטע מאוחסן וניגון מפורש](diagrams/av-check-flow.svg)

<a id="start-the-check"></a>

## התחלת הבדיקה

1. כוונו את הטלוויזיה, הרמקולים או האוזניות לעוצמה נוחה. הבדיקה משתמשת בעוצמה הנוכחית של הנגן ומבטלת זמנית את השתקת הווידאו שלו; היא אינה מעלה את עוצמת המערכת בטלוויזיה.
2. פתחו את תפריט הנגן ובחרו **מידע**, אחר כך **אודיו**, ואז **ניגון**. פתיחת התפריט בלבד אינה מורידה או מנגנת את הקטע.
3. צפו במסך והאזינו לרצף שלהלן. לסיום מוקדם השתמשו ב-**מידע ← אודיו ← עצירה**.

הבדיקה משתמשת בנתיב הניגון המרכזי המנוהל של HTML5 כשהנגן במצב סרק, או כשהטלוויזיה החיה מנוגנת או מושהית. היא דוחה בקשת VOD/ארכיון פעילה, בקשה חיה שעדיין נטענת ומצב המתנה. היא גם אינה זמינה כאשר מתאם מכשיר מחליף את מנוע הליבה, לרבות **PC2/Video.js** והחלפות למנועים מקוריים; שימוש ברכיב וידאו HTML5 בלבד אינו הופך מתאם למתאים. דחייה אינה מחליפה ניגון קיים. עצרו תחילה את הבקשה הנוכחית כדי לבדוק ממצב סרק; זה אינו מאפשר את הבדיקה במתאמים האלה. תוויות התפריט תואמות לשפת הממשק שנבחרה.

<a id="what-you-should-see-and-hear"></a>

## מה אמורים לראות ולשמוע

ברקע נעה תבנית בדיקה. סמנים לבנים קצרים מהבהבים בחצי העליון השמאלי או הימני, במקביל לפולסי צליל חלשים באורך כ-150 ms:

- **0–2 שניות:** פולס של 440 Hz בערוץ השמאלי בכל שנייה, עם הבהוב הסמן השמאלי.
- **2–4 שניות:** פולס של 880 Hz בערוץ הימני, עם הסמן הימני.
- **4–6 שניות:** שני הערוצים פולסים, עם שני הסמנים.
- **6–8 שניות:** התבנית ממשיכה לנוע ללא צליל. השקט מכוון.

טלוויזיה חד-ערוצית או ערבול כלפי מטה עשויים לנגן את שני הערוצים דרך רמקול אחד. בדקו בעצמכם את המסך הפיזי ואת יציאת האודיו. הנגן אינו מודד את פלט הרמקולים ואינו מספק קביעת A/V אוטומטית של עבר/נכשל.

<a id="where-the-clip-comes-from"></a>

## מקור הקטע

הנגן משתמש בכתובת HTTPS המוחלטת הזו:

[`https://mantra-basin-76mq.here.now/diagnostics/av-v1.mp4`](https://mantra-basin-76mq.here.now/diagnostics/av-v1.mp4)

הוא מבקש את הקטע רק כשבוחרים **ניגון**, ולעולם לא כטעינה מוקדמת בהפעלה. גודל הקובץ **464 652 בתים**, עם וידאו H.264 baseline ב-640×360 / 25 fps ואודיו AAC בסטריאו. הקובץ מוחרג מחבילות Web, OTTPlay Server, Tauri, Capacitor ומכולות. [קובץ המקור](../diagnostics/av-v1.mp4), המחולל והמאמת נשארים במאגר; הם אינם חלופה לא מקוונת בנגן המותקן.

נדרשים אינטרנט וחיבור HTTPS תקין למארח הזה. אין חלופה מצורפת או URL אבחון חלופי. פתיחת הקישור בדפדפן עשויה לעזור לבדוק את זמינות הקובץ, אך אינה בוחנת את הבעלות על מפענח הנגן או את התנהגות החזרה לערוץ. שירות האחסון מקבל מידע חיבור רגיל; ראו [פרטי פרטיות](privacy-policy.md#optional-hosted-audio-video-check).

<a id="how-playback-returns"></a>

## החזרה לניגון

הבדיקה משתמשת במפענח הראשי ומחליפה זמנית את התמונה החיה. היא מסתיימת בסוף הקטע, אחרי **אודיו ← עצירה**, או בשגיאת מדיה. **מגבלת בטיחות של 15 שניות מתחילה עם קבלת הבדיקה** וכוללת גם את הטעינה; לכן הורדה אטית עשויה להסתיים לפני שכל שמונה השניות נוגנו.

במסלולים האלה הנגן מנסה לשחזר את הבקשה החיה שנלכדה לקצה השידור החי, כולל מצב ההשהיה שלה, רק אם היא עדיין שייכת למקור הנוכחי וניגון חלופי לא השתלט. כתובת השידור נפתרת מחדש; השחזור עדיין תלוי בספק וברשת. בדיקה שהחלה בסרק חוזרת לסרק.

פקודת הניגון הרגילה **Stop**, מצב המתנה או בחירת ערוץ אחר מבטלים את הבדיקה בלי להפעיל מחדש את הערוץ שנלכד. שינוי המקור או ההפעלה שלו מונע גם שחזור מיושן. ביציאה הבדיקה מבטלת את שינוי ההשתקה הזמני שלה; אם השתקתם בזמן שהיא פועלת, ההשתקה נשארת. היא אינה משנה העדפת מנוע שמורה, אינה כותבת שניות בדיקה להיסטוריית הערוץ ואינה מפרסמת למערכת ההפעלה סיום ערוץ שגוי או מטא-נתוני בדיקה.

<a id="if-the-result-is-unexpected"></a>

## אם התוצאה אינה צפויה

- **הבדיקה אינה מתחילה:** ודאו שהנגן בסרק או בערוץ חי שכבר מנוגן/מושהה דרך נתיב HTML5 המרכזי המנוהל, ללא החלפת מנוע בידי המכשיר. מצב לא נתמך או שגיאת מדיה עשויים להציג **“Stream could not be played”**.
- **דבר אינו נטען או שהבדיקה נסגרת מוקדם:** בדקו גישה לאינטרנט ואת קישור ה-HTTPS הישיר. שגיאת רשת או פקיעת הזמן אינן ראיה שהמפענח או הרמקולים פגומים. שחזרו את הקישוריות לפני בחירה בניגון שוב.
- **תמונה ללא צליל:** שתי השניות האחרונות שקטות במכוון. בשש הראשונות בדקו השתקה/עוצמה בנגן, עוצמת טלוויזיה, יציאת אודיו נבחרת וחיבור רמקולים/אוזניות.
- **רק רמקול פיזי אחד מנגן:** בדקו תחילה אם הטלוויזיה משתמשת ביציאה חד-ערוצית או בערבול, לפני שמתייחסים לכך ככשל ניתוב ערוצים.

זו בדיקה קצרה של MP4 מוכר דרך נתיב התמונה/אודיו המרכזי המנוהל של HTML5. היא אינה מוכיחה שזרם ספק, HLS/DASH, DRM, אודיו רב-ערוצי או ניגון ברזולוציה גבוהה יותר יעבדו, ואינה מודדת קיבולת רשת או שיהוי סנכרון. מגבלות איכות והגדרות זרמי גיבוי חיים אינן משנות את קטע האבחון הזה.

הבעלות והניקוי נבדקים ב-[`tests/test_media_backend.cjs`](../tests/test_media_backend.cjs) וב-[`tests/test_port_engine_lifecycle.cjs`](../tests/test_port_engine_lifecycle.cjs). בדיקות פענוח ומחזור חיים אוטומטיות אינן תחליף לצפייה והאזנה במכשיר האמיתי; מדריך זה אינו טוען לתוצאה חדשה במכשיר פיזי.
