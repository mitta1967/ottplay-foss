<a id="start-the-check"></a>

## เริ่มการตรวจ

1. ตั้งเสียงโทรทัศน์ ลำโพง หรือหูฟังให้ฟังสบาย การตรวจใช้ระดับเสียงปัจจุบันของตัวเล่นและยกเลิกการปิดเสียงวิดีโอชั่วคราว ไม่เพิ่มเสียงระบบของโทรทัศน์
2. เปิดเมนูตัวเล่น เลือก **ข้อมูล** ตามด้วย **เสียง** และ **เล่น** การเปิดเมนูอย่างเดียวไม่ดาวน์โหลดหรือเล่นคลิป
3. ดูหน้าจอและฟังตามลำดับด้านล่าง หากต้องการจบก่อน ใช้ **ข้อมูล → เสียง → หยุด**

การตรวจใช้เส้นทางเล่น HTML5 แกนหลักที่จัดการให้ เมื่อตัวเล่นว่าง หรือกำลังเล่น/พักทีวีสด โดยปฏิเสธคำขอ VOD/ย้อนหลังที่ทำงานอยู่ คำขอสดที่ยังโหลด และโหมดสแตนด์บาย นอกจากนี้ยังใช้ไม่ได้เมื่ออะแดปเตอร์อุปกรณ์แทนที่เอนจินหลัก รวม **PC2/Video.js** และการแทนด้วยเอนจินเนทีฟ การใช้เพียงองค์ประกอบ video ของ HTML5 ไม่ทำให้อะแดปเตอร์เข้าเกณฑ์ การปฏิเสธไม่แทนที่การเล่นปัจจุบัน หากต้องการทดสอบขณะว่างให้หยุดคำขอปัจจุบันก่อน แต่นั่นไม่ได้เปิดการตรวจบนอะแดปเตอร์ดังกล่าว ป้ายเมนูใช้ภาษาของส่วนติดต่อที่เลือก

<a id="what-you-should-see-and-hear"></a>

## สิ่งที่ควรเห็นและได้ยิน

พื้นหลังเป็นลายทดสอบเคลื่อนไหว เครื่องหมายสีขาวสั้น ๆ กะพริบในครึ่งบนซ้ายหรือขวาตรงกับพัลส์เสียงเบายาวประมาณ 150 ms:

- **0–2 วินาที:** พัลส์ 440 Hz ในช่องซ้ายทุกวินาที พร้อมเครื่องหมายซ้ายกะพริบ
- **2–4 วินาที:** พัลส์ 880 Hz ในช่องขวา พร้อมเครื่องหมายขวา
- **4–6 วินาที:** ทั้งสองช่องมีพัลส์ พร้อมเครื่องหมายทั้งคู่
- **6–8 วินาที:** ลายเคลื่อนไหวต่อโดยไม่มีเสียง ช่วงเงียบนี้ตั้งใจไว้

โทรทัศน์โมโนหรือการดาวน์มิกซ์อาจเล่นทั้งสองช่องจากลำโพงเดียว ตรวจหน้าจอจริงและเอาต์พุตเสียงด้วยตัวเอง ตัวเล่นไม่วัดเสียงออกจากลำโพงและไม่ตัดสินผ่าน/ไม่ผ่าน A/V โดยอัตโนมัติ

<a id="where-the-clip-comes-from"></a>

## ที่มาของคลิป

ตัวเล่นใช้ที่อยู่ HTTPS แบบสัมบูรณ์นี้:

[`https://mantra-basin-76mq.here.now/diagnostics/av-v1.mp4`](https://mantra-basin-76mq.here.now/diagnostics/av-v1.mp4)

ขอคลิปเฉพาะเมื่อเลือก **เล่น** ไม่โหลดล่วงหน้าตอนเริ่มต้น ไฟล์มีขนาด **464 652 ไบต์** เป็นวิดีโอ H.264 baseline 640×360 / 25 fps และเสียง AAC สเตอริโอ ไฟล์ไม่รวมอยู่ในแพ็กเกจ Web, OTTPlay Server, Tauri, Capacitor หรือคอนเทนเนอร์ [ไฟล์ต้นฉบับ](../diagnostics/av-v1.mp4) ตัวสร้างและตัวตรวจสอบยังอยู่ในรีโพซิทอรี แต่ไม่ใช่ตัวสำรองออฟไลน์ในตัวเล่นที่ติดตั้ง

ต้องมีอินเทอร์เน็ตและการเชื่อมต่อ HTTPS ที่ใช้งานได้กับโฮสต์นั้น ไม่มีไฟล์สำรองในแพ็กเกจหรือ URL วินิจฉัยสำรอง การเปิดลิงก์ด้านบนในเบราว์เซอร์ช่วยตรวจว่าไฟล์พร้อมใช้งานหรือไม่ แต่ไม่ได้ทดสอบความเป็นเจ้าของตัวถอดรหัสของตัวเล่นหรือพฤติกรรมกลับสู่ช่อง บริการโฮสต์ได้รับข้อมูลการเชื่อมต่อทั่วไป ดู[รายละเอียดความเป็นส่วนตัว](privacy-policy.md#optional-hosted-audio-video-check)

<a id="how-playback-returns"></a>

## การกลับสู่การเล่นเดิม

การตรวจใช้ตัวถอดรหัสหลักและแทนภาพสดชั่วคราว จบเมื่อคลิปหมด หลังเลือก **เสียง → หยุด** หรือเมื่อสื่อเกิดข้อผิดพลาด **เส้นตายความปลอดภัย 15 วินาทีเริ่มเมื่อยอมรับการตรวจ** และรวมเวลาโหลดด้วย การดาวน์โหลดช้าจึงอาจสิ้นสุดก่อนเล่นครบแปดวินาที

ในกรณีเหล่านี้ ตัวเล่นพยายามคืนคำขอสดที่บันทึกไว้ไปยังจุดสดปัจจุบัน รวมสถานะพัก เฉพาะเมื่อคำขอนั้นยังเป็นของแหล่งปัจจุบันและไม่มีการเล่นอื่นมาแทนที่ URL สดถูกหาใหม่ การคืนยังขึ้นกับผู้ให้บริการและเครือข่าย การตรวจที่เริ่มขณะว่างกลับสู่สถานะว่าง

คำสั่งเล่นปกติ **Stop** โหมดสแตนด์บาย หรือการเลือกช่องอื่นยกเลิกการตรวจโดยไม่เริ่มช่องที่บันทึกไว้อีก การเปลี่ยนแหล่งหรือเซสชันของแหล่งก็ป้องกันการคืนข้อมูลเก่าเช่นกัน เมื่อออก การตรวจย้อนการยกเลิกปิดเสียงชั่วคราวของตน หากคุณปิดเสียงระหว่างตรวจ เสียงจะยังปิดอยู่ การตรวจไม่เปลี่ยนค่าเอนจินที่บันทึก ไม่เขียนวินาทีทดสอบในประวัติช่อง และไม่ส่งเหตุการณ์จบช่องที่ไม่จริงหรือเมทาดาทาทดสอบให้ OS

<a id="if-the-result-is-unexpected"></a>

## หากผลไม่เป็นไปตามคาด

- **เริ่มตรวจไม่ได้:** ยืนยันว่าตัวเล่นว่างหรืออยู่บนช่องสดที่กำลังเล่น/พักอยู่แล้วผ่านเส้นทาง HTML5 แกนหลักที่จัดการให้ โดยไม่มีเอนจินอุปกรณ์มาแทนที่ สถานะที่ไม่รองรับหรือข้อผิดพลาดสื่ออาจแสดง **“Stream could not be played”**
- **ไม่มีอะไรโหลดหรือการตรวจปิดเร็ว:** ตรวจอินเทอร์เน็ตและลิงก์ HTTPS โดยตรง ข้อผิดพลาดเครือข่ายหรือหมดเวลาไม่ได้พิสูจน์ว่าตัวถอดรหัสหรือลำโพงเสีย คืนการเชื่อมต่อก่อนเลือกเล่นใหม่
- **มีภาพแต่ไม่มีเสียง:** สองวินาทีสุดท้ายตั้งใจให้เงียบ ในหกวินาทีแรกให้ตรวจปิดเสียง/ระดับเสียงของตัวเล่น ระดับเสียงโทรทัศน์ เอาต์พุตเสียงที่เลือก และสายลำโพง/หูฟัง
- **มีเสียงจากลำโพงจริงเพียงตัวเดียว:** ตรวจว่าโทรทัศน์ใช้เอาต์พุตโมโนหรือดาวน์มิกซ์ก่อนสรุปว่าเป็นความผิดพลาดการส่งสัญญาณช่อง

นี่คือการตรวจสั้น ๆ ด้วย MP4 ที่ทราบเนื้อหาผ่านเส้นทางภาพ/เสียง HTML5 แกนหลักที่จัดการให้ ไม่ยืนยันว่าสตรีมผู้ให้บริการ HLS/DASH, DRM, เสียงหลายช่อง หรือความละเอียดสูงกว่าจะใช้ได้ และไม่วัดความจุเครือข่ายหรือความหน่วงการซิงก์ เพดานคุณภาพและการตั้งค่าสตรีมสดสำรองไม่เปลี่ยนคลิปวินิจฉัยนี้
