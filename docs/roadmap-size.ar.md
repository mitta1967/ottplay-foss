![مقارنة جميع شيفرات JavaScript للمشغل باستخدام سلسلة الأدوات نفسها](diagrams/roadmap-size.svg)

تحتفظ هذه الصفحة بقياسات JavaScript من لقطات المصدر أدناه. ولا تقيس المراجعة الحالية أو حزم التثبيت أو حركة الشبكة.

في المقارنة الأولية، زادت نقطة الدخول الرئيسية مع جميع عائلات المزوّدين الاختيارية بمقدار **31 128 بايت خام / 9 759 بايت gzip**، أي نحو **3.23% / 3.20%**. هذه زيادة في تكلفة الميزات، وليست ادعاءً بتحسين الحجم أو سرعة التنفيذ. يظل Xtream محمّلًا عند الطلب؛ ونقله خارج نقطة الدخول لا يحذفه من المجموع.

يقارن القياس أرشيفَي المصدر النظيفين `bbf9ca7b` و`cae971da`، وكلاهما بالإصدار 1.1.55، باستخدام Node 26.8.2 وTypeScript 5.9.3 وTerser 5.51.2 وzlib 1.2.12. ويستخدم مجمّع ES5 الإنتاجي والمُحسّن وسياسة التسمية وهوية المصدر النظيف الصحيحة. يُطبّق gzip بالمستوى 9 على كل أصل ناتج على حدة.

- نقطة دخول الويب: 848 092 / 262 392 → 874 926 / 270 321 بايت خام/gzip.
- نقطة دخول الويب + جميع المزوّدين: 964 459 / 305 344 → 995 587 / 315 103.
- نقطة الدخول الأصلية: 848 050 / 262 460 → 874 884 / 270 372.
- نقطة الدخول الأصلية + جميع المزوّدين: 964 417 / 305 412 → 995 545 / 315 154.
- يزداد M3U الاختياري بمقدار 184 بايت خام / 82 gzip؛ ويبلغ Xtream الجديد 4 110 / 1 748. العائلات الاختيارية الست الأخرى متطابقة بايتًا ببايت.

قبل نقل المقطع إلى here.now، أضاف تغيير عنوانه إلى مسار محلي يبدأ من الجذر بايت JavaScript خامًا واحدًا في هذا التسلسل التاريخي. وهذا ليس قياسًا للعنوان المستضاف لاحقًا. يضيف إصلاح إعادة محاولة تحليل HLS المحدودة 37 بايت خام / 36 gzip في مقارنة معزولة للقطة نفسها ([الدليل](evidence/parse-recovery-size-20261015.json)). ويضيف إصلاح ملكية التسليم Auto الأصلي 101 بايت خام / 39 gzip أخرى ([الدليل](evidence/auto-recovery-size-20261015.json)). يصبح المجموع الخام قبل إصلاحات تراجع الإتاحة 995 726 بايت؛ وقد تتغير هوية البناء وبايتات gzip في الالتزام النهائي. يظل `build/reports/classic-bundle.json` النهائي و`npm run check:size` المرجع للمراجعة الدقيقة المسلّمة. يقيس البناء النظيف التالي `652726f8`، بما فيه إصلاحات تركيز المؤشر والحوارات، **995 858 بايت خام / 315 207 gzip** لمشغل الويب الكامل ([دليل الناتج النهائي](evidence/roadmap-final-size-20261015.json)). تبلغ نقطة دخوله 875 197 / 270 425؛ والمجاميع الأصلية 995 816 / 315 259. حافظت حدود تلك اللقطة على الهامش السابق للأصلي/Node/لاحقة الإصدار: 875 300 خام / 271 600 gzip للدخول؛ و996 100 / 316 400 للدخول مع المزوّدين.

## التكامل بعد النسخة التجريبية

![JavaScript الكامل بعد دمج beta.4](diagrams/post-beta-size.svg)

تعيد المقارنة اللاحقة إنتاج مصدر beta.4 `39287792` مقابل بيئة التشغيل `9663b681`، بما فيها تكامل Plex واستعادة الإعدادات التالفة، باستخدام Node 26.8.2 وRollup 4.64.5 وTerser 5.51.2 نفسها:

- نقطة دخول الويب: 848 315 / 262 443 → 879 533 / 271 761 بايت خام/gzip.
- نقطة دخول الويب + جميع المزوّدين: 964 876 / 305 452 → 1 000 388 / 316 600.
- نقطة الدخول الأصلية + جميع المزوّدين: 964 834 / 305 520 → 1 000 346 / 316 654.
- زيادة حمولة الويب الكاملة: **35 512 / 11 148 بايت (3.68% / 3.65%)**.

يحسب الخط الأساسي سبع عائلات مزوّدين، والتكامل ثماني عائلات بما فيها Xtream عند الطلب. كانت حدود دخول تلك اللقطة 879 900 / 273 000، والحدود الكلية 1 000 800 / 317 800، مع مساحة للأصلي وNode وهوية الإصدار. يعيد البناءان الإنتاجيان المحليان إنشاء خمسة ملفات تشغيل متتبعة، ويحذفان ادعاء مراجعة المصدر النظيف. هذه نواتج معاد إنتاجها محليًا، وليست ملفات النسخة التجريبية الثنائية المنشورة. تسجل [أدلة الخط الأساسي](evidence/post-beta-baseline-size-20261015.json) و[أدلة التكامل](evidence/post-beta-candidate-size-20261015.json) إصدارات الأدوات والبصمات وهذا القيد. يشرح [تقرير التنفيذ](implementation-report.ar.md#post-beta-integration-and-review) الإصلاحات والتحقق.

**النطاق:** تستثني مجاميع JavaScript محركات الوسائط الخارجية وقواميس اللغات وCSS والصور والفيديو. حملت حزم المشغل التاريخية أيضًا **مقطع A/V بحجم 464 652 بايت** خارج المجاميع السابقة. تسليمه الحالي منفصل عن تلك القياسات:

- **المستودع:** يبقى `diagnostics/av-v1.mp4` مع مولّده ومدققه لإتاحة إعادة الإنتاج. الاحتفاظ بملف مصدر لا يدرجه في الحزمة.
- **الحزم:** يستثني Web/OTTPlay Server وTauri وCapacitor وDocker المقطع. يزيل ذلك 464 652 بايت خامًا من أصول الوسائط، وليس انخفاضًا مقاسًا قدره 464 652 بايت في مثبّت مضغوط. يؤثر تنسيق الأرشيف وتغييرات البناء الأخرى في ذلك الحجم.
- **الشبكة:** يجلب المشغل المقطع من here.now فقط عندما يبدأ المستخدم [فحص A/V](audio-video-check.ar.md). يحتاج الفحص إلى الإنترنت؛ ولا يُجلب المقطع للتشغيل عند بدء التطبيق.

تبقى قياسات JavaScript التاريخية أعلاه دون تغيير. قياس أثر العنوان المستضاف في JavaScript أو مثبّت حالي يتطلب مقارنة جديدة. ملفات README المترجمة الـ88 هي وثائق للمستودع وليست حمولة المشغل. لا تُستنتج من مقارنة البايتات أي ادعاءات بشأن زمن البدء أو معدل الإطارات أو الذاكرة أو الأداء على مستوى حجم الكتالوج. تتطلب هذه قياسات منفصلة على الأجهزة المستهدفة.
