![একই টুলচেইনে প্লেয়ারের সব JavaScript-এর তুলনা](diagrams/roadmap-size.svg)

এই পৃষ্ঠায় নিচের সোর্স স্ন্যাপশটগুলোর JavaScript পরিমাপ সংরক্ষিত আছে। এগুলো বর্তমান রিভিশন, ইনস্টলেশন প্যাকেজ বা নেটওয়ার্ক ট্র্যাফিক মাপে না।

প্রথম তুলনায় প্রধান এন্ট্রি ও সব ঐচ্ছিক সরবরাহকারী পরিবার মিলে **31 128 অসংকুচিত বাইট / 9 759 gzip বাইট**, প্রায় **3.23% / 3.20%**, বেড়েছে। এটি সুবিধা যোগ করার খরচ বৃদ্ধি, আকার বা চলার গতির উন্নতির দাবি নয়। Xtream এখনও প্রয়োজনে লোড হয়; এন্ট্রির বাইরে নিলেও মোট হিসাব থেকে বাদ যায় না।

পরিমাপটি পরিষ্কার সোর্স আর্কাইভ `bbf9ca7b` ও `cae971da` তুলনা করে, দুটোই সংস্করণ 1.1.55, Node 26.8.2, TypeScript 5.9.3, Terser 5.51.2 ও zlib 1.2.12 দিয়ে। প্রোডাকশন ES5 অ্যাসেম্বলার, অপ্টিমাইজার, নামের নীতি ও পরিষ্কার সোর্সের সঠিক পরিচয় ব্যবহার করা হয়। প্রতিটি উৎপন্ন সম্পদে gzip স্তর 9 আলাদা করে প্রয়োগ হয়।

- ওয়েব এন্ট্রি: 848 092 / 262 392 → 874 926 / 270 321 অসংকুচিত/gzip বাইট।
- ওয়েব এন্ট্রি + সব সরবরাহকারী: 964 459 / 305 344 → 995 587 / 315 103।
- নেটিভ এন্ট্রি: 848 050 / 262 460 → 874 884 / 270 372।
- নেটিভ এন্ট্রি + সব সরবরাহকারী: 964 417 / 305 412 → 995 545 / 315 154।
- ঐচ্ছিক M3U বাড়ে 184 অসংকুচিত / 82 gzip বাইট; নতুন Xtream হলো 4 110 / 1 748। অন্য ছয়টি ঐচ্ছিক পরিবার বাইটে বাইটে এক।

ক্লিপ here.now-এ নেওয়ার আগে, URL রুট থেকে শুরু হওয়া স্থানীয় পথে বদলালে এই ঐতিহাসিক ধারায় এক অসংকুচিত JavaScript বাইট যোগ হয়েছিল। এটি পরের হোস্ট করা URL-এর মাপ নয়। সীমিত HLS পার্স-পুনঃচেষ্টা সংশোধন একই স্ন্যাপশটের বিচ্ছিন্ন তুলনায় 37 অসংকুচিত / 36 gzip বাইট যোগ করে ([প্রমাণ](evidence/parse-recovery-size-20261015.json))। নেটিভ Auto হস্তান্তরের মালিকানা সংশোধন আরও 101 অসংকুচিত / 39 gzip বাইট যোগ করে ([প্রমাণ](evidence/auto-recovery-size-20261015.json))। অ্যাক্সেসিবিলিটির রিগ্রেশন সংশোধনের আগে মোট অসংকুচিত আকার 995 726 বাইট; শেষ কমিটে বিল্ডের পরিচয় ও gzip বাইট বদলাতে পারে। নির্দিষ্ট সরবরাহ করা রিভিশনের চূড়ান্ত ভিত্তি হলো শেষ `build/reports/classic-bundle.json` ও `npm run check:size`। পরের পরিষ্কার বিল্ড `652726f8`, যাতে পয়েন্টার/ডায়ালগ ফোকাস সংশোধন আছে, সম্পূর্ণ ওয়েব প্লেয়ারের জন্য **995 858 অসংকুচিত / 315 207 gzip বাইট** মাপে ([চূড়ান্ত আর্টিফ্যাক্টের প্রমাণ](evidence/roadmap-final-size-20261015.json))। তার এন্ট্রি 875 197 / 270 425; নেটিভ মোট 995 816 / 315 259। সেই স্ন্যাপশটের সীমা আগের নেটিভ/Node/রিলিজ প্রত্যয়ের বাড়তি জায়গা রেখেছে: এন্ট্রির জন্য 875 300 অসংকুচিত / 271 600 gzip; এন্ট্রি + সরবরাহকারীর জন্য 996 100 / 316 400।

<a id="post-beta-integration"></a>

## বিটার পরের সমন্বয়

![beta.4 সমন্বয়ের পরে সব JavaScript](diagrams/post-beta-size.svg)

পরের তুলনা beta.4 সোর্স `39287792` পুনরুৎপাদন করে runtime `9663b681`-এর বিপরীতে, Plex সমন্বয় ও নষ্ট সেটিং পুনরুদ্ধারসহ, একই Node 26.8.2, Rollup 4.64.5 ও Terser 5.51.2 ব্যবহার করে:

- ওয়েব এন্ট্রি: 848 315 / 262 443 → 879 533 / 271 761 অসংকুচিত/gzip বাইট।
- ওয়েব এন্ট্রি + সব সরবরাহকারী: 964 876 / 305 452 → 1 000 388 / 316 600।
- নেটিভ এন্ট্রি + সব সরবরাহকারী: 964 834 / 305 520 → 1 000 346 / 316 654।
- সম্পূর্ণ ওয়েব পেলোড বৃদ্ধি: **35 512 / 11 148 বাইট (3.68% / 3.65%)**।

ভিত্তি সংস্করণে সাতটি সরবরাহকারী পরিবার ধরা হয়; সমন্বয়ে আটটি, প্রয়োজনে লোড হওয়া Xtream-সহ। সেই স্ন্যাপশটের এন্ট্রি সীমা ছিল 879 900 / 273 000; মোট সীমা 1 000 800 / 317 800, নেটিভ, Node ও রিলিজ পরিচয়ের জন্য জায়গা রেখে। দুটো স্থানীয় প্রোডাকশন বিল্ডই ট্র্যাক করা পাঁচটি runtime ফাইল আবার তৈরি করে এবং পরিষ্কার সোর্স রিভিশনের দাবি বাদ দেয়। এগুলো স্থানীয়ভাবে পুনরুৎপাদিত আর্টিফ্যাক্ট, প্রকাশিত বিটা বাইনারি নয়। টুলের সংস্করণ, হ্যাশ ও এই সীমা [ভিত্তির প্রমাণে](evidence/post-beta-baseline-size-20261015.json) এবং [সমন্বয়ের প্রমাণে](evidence/post-beta-candidate-size-20261015.json) লেখা আছে। [বাস্তবায়ন প্রতিবেদন](implementation-report.bn.md#post-beta-integration-and-review) সংশোধন ও যাচাই ব্যাখ্যা করে।

**পরিধি:** এই JavaScript মোটে বাইরের মিডিয়া ইঞ্জিন, ভাষার অভিধান, CSS, ছবি ও ভিডিও নেই। পুরোনো প্লেয়ার প্যাকেজে **464 652-বাইটের A/V ক্লিপও** ছিল, যা ওপরের মোটের বাইরে। তার বর্তমান সরবরাহ এই পরিমাপ থেকে আলাদা:

- **রিপোজিটরি:** পুনরুৎপাদনের সুবিধায় `diagnostics/av-v1.mp4` তার জেনারেটর ও যাচাইকারীর সঙ্গে থাকে। সোর্স ফাইল রাখলেই তা প্যাকেজে অন্তর্ভুক্ত হয় না।
- **প্যাকেজ:** Web/OTTPlay Server, Tauri, Capacitor ও Docker ক্লিপ বাদ দেয়। এতে 464 652 অসংকুচিত মিডিয়া বাইট সরানো হয়; এটি সংকুচিত ইনস্টলারে মাপা 464 652-বাইট হ্রাস নয়। আর্কাইভের ধরন ও অন্যান্য বিল্ড পরিবর্তন সেই আকারে প্রভাব ফেলে।
- **নেটওয়ার্ক:** ব্যবহারকারী [A/V পরীক্ষা](audio-video-check.bn.md) শুরু করলেই শুধু প্লেয়ার here.now থেকে ক্লিপ আনে। পরীক্ষার জন্য ইন্টারনেট লাগে; চালুর সময় প্লেব্যাকের জন্য ক্লিপ আনা হয় না।

ওপরের ঐতিহাসিক JavaScript পরিমাপ অপরিবর্তিত থাকে। হোস্ট করা URL-এর JavaScript বা বর্তমান ইনস্টলারের ওপর প্রভাব মাপতে নতুন তুলনা দরকার। 88টি স্থানীয়কৃত README রিপোজিটরির নথি, প্লেয়ারের পেলোড নয়। এই বাইট তুলনা থেকে চালুর সময়, ফ্রেম রেট, মেমরি বা বড় ক্যাটালগের কর্মক্ষমতার দাবি করা যায় না। সেগুলোর জন্য লক্ষ্য যন্ত্রে আলাদা পরিমাপ লাগে।
